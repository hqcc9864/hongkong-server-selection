## 线路：只写「CN2 优化」的方案，联通和移动用户照样卡

真正的香港三网精品回程，要求电信走 CN2 GIA（AS4809）、联通走 9929（AS9929/AS10099）、移动走 CMIN2（AS58807），三条线同时优化。少任何一条，对应运营商的用户在晚高峰就会掉进普通 163 或 4837 的拥堵里。

CN2 本身还分两档。GT（Global Transit）是半程优化，2019 年之后在很多地区的拥堵程度已经接近普通 163；GIA（Global Internet Access）才是全程精品。CN2 GIA 的批发带宽成本在部分市场能到 $120/Mbps 这个量级，所以标了「CN2 优化」却不说清是 GT 还是 GIA 的方案，你基本可以按较低那档预期。

GoMami 官方文档在产品页里明确写了对 CN2 / 9929 / CMIN2 三条路由做深度优化，但没列出具体 AS 号；三条线分别对应哪个 AS 是对照第三方路由追踪得出的。第三方实测的口径是：三网 RTT 普遍在 50ms 以内，广东等省份能到 8–12ms。

对买家的实际意义是：如果你的用户集中在某一个运营商，只优化电信的方案也能用；只要用户是三网混合，就必须三条线齐全。

## 硬件：四条产品线各管一件事

Turin 主打存储 IO 和内存带宽，Peak X5 主打单核频率，Pulse 主打每美元拿到的资源量，Forge 主打整机独享。它们分别解决不同问题，不存在简单的配置高低排列。

**HKG.Turin** 用 AMD EPYC 9575F（Zen 5 架构），配 PCIe Gen5 的 U.2 NVMe 和 DDR5 6400MHz 内存。价值主要体现在存储 IO 上，第三方测过 4K 随机读写 4166 MB/s、106.6k IOPS。跑数据库、AI 接口后端、实时数据分析这类对 IO 敏感的活，Turin 比同价位的其他线更合适。

**HKG.Peak X5** 卖的是单核频率，Ryzen 9 9950X 最高 5.7GHz。MySQL 的 InnoDB 单条查询通常只能单线程跑，API 网关的响应延迟、CS 服务器的 tickrate 全都吃单核。代价是磁盘小，三个套餐分别只有 40GB / 60GB / 80GB NVMe。有个第三方测评提到 Peak.X5.Mini 锁了 IO，同样用 fio 生成 10G 测试文件，和 Pulse.Mini 差了大约 3 倍，但跑 WordPress 这类应用仍然够用。多花的钱主要买在 CPU 上。

**HKG.Pulse** 用 EPYC 7763，基础频率低一些，同价位给的 vCPU 和内存更多，带宽上限低一档。适合多站点托管、容器集群、CDN 节点这类并发型负载。它和 Turin、Peak 用的是同一套网络，省下的钱体现在 CPU 代次和端口带宽上。

**HKG.Forge** 是真正的独立服务器，不是 VPS。AMD EPYC 7663，56 核 112 线程，基于 TYAN B8033 平台，128GB 或 256GB 内存整机独享，没有邻居也没有超售。它解决的是「VPS 已经被同机其他租户拖累」的问题。

## 三条写在文档里、但多数测评不提的规则

## 常见问题

**香港服务器需要备案吗？** 不需要。香港节点不强制备案，域名直接解析就能上线，这是它相对内地服务器最直接的优势之一。

**RTT 50ms 是承诺还是实测？** 官网写的是「RTT < 50ms across mainland China」，属于产品目标。第三方实测普遍落在这个范围内，广东等南方省份更低。具体到你的城市和运营商，会有波动。

**600 Gbps DDoS 防护是全系标配吗？** 官网首页写的是「up to 600 Gbps mitigation capacity」，读起来像标配；官方文档的表述更精确——默认包含尽力而为的防护，600 Gbps 高级清洗是可选项。业务确实需要大流量清洗的，先问清楚当前套餐包含哪一档。

**能装 Windows 吗？** 只有 Turin.Pro / Ultra、Pulse.Pro / Ultra、Peak.X5.Pro 标了 Windows-ready。Mini 和 Air 档默认 Linux，需要 Windows 的最少从 Pro 档起。

**流量超了会停机吗？** VPS 不会停机，会限速，限到多少取决于产品规格，官方没有公布统一数值。Forge 独立服务器按 $0.06/GB 计费，不限速。

**能中途升级配置吗？** 可以，但要提交工单，面板里没有自助升降配入口。
